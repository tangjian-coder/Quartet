# SDF 粗筛（Safe-Margin Coarse Test）设计文档

本文档记录 `evaluateSDF` 中粗边界快速通道的设计依据：ALM 乘子 λ 的更新机制、粗筛成立的充分条件、margin 参数的推导。

## 1. 背景

`evaluateSDF` 是求解热点：每帧 4 个 crop 角点 × 40 条精细边界边的距离计算。粗筛思路：

- 每帧预计算 4 条**粗边**（每侧边界 11 个点的两端连线）+ 内偏量
- 角点先做 4 次点积的粗筛：确认罚项惰性（`d > λf/ρ`）则报 `g = -d, J = 0`，跳过 40 边细算
- 贴线区与罚项活跃区才走精细计算

粗筛"跳过细算"要安全，必须同时满足两个断言：

| 断言 | 内容 | 由什么保证 |
|---|---|---|
| 几何正确 | 粗筛放行的角真的在多边形内 | 内偏量 ≥ 折线最大内凹 + 角部近似误差 |
| 罚项惰性 | 跳过的角罚项/梯度确实为零 | 判定式 `d > λf/ρ` 直接判定罚项惰性本身（精确） |

## 2. GN + ALM 中的 λ 更新机制

### 2.1 罚项结构

每个角点一条不等式约束 `g ≤ 0`（g = 前向 SDF，界内为负）。ALM 罚项：

```
penalty = max(0, λ + ρ·g)² / (2ρ)
```

- `λ`：拉格朗日乘子（积累的约束压力）
- `ρ`：罚参数（外层每轮 ×2：20→40→80→160→320）

**罚项活跃条件**（对 H/b 有贡献）：

```
λ + ρ·g > 0   ⟺   λ/ρ > |g|      (界内时 g<0, |g| 为深度)
```

跳过条件 `d > λf/ρ` 即上式的像素制否定形式（d 是角到内偏粗边界的深度下界）：罚项与 λ 更新（`λ ← max(0, λ+ρ·g·inv_f)`）同时 clamp 到零，跳过是精确操作而非近似。

### 2.2 λ 更新与 ρ 更新

```cpp
// 每轮 GN 结束后:
lambda = max(0, lambda + rho * g * inv_f);   // 越界积累压力, 界内泄压
rho = min(rho * 2, rho_max);                 // 无条件翻倍
```

λ 的四种典型轨迹（px 制阈值 `λf/ρ`，即罚项活跃区的深度上限）：

| 场景 | g 的取值 | λ 趋势 |
|---|---|---|
| A 持续越界 | g=+0.4px × 5 轮 | 涨到 λf/ρ ≈ 0.78px（渐近 2·g_max） |
| B 越界后压回 | +0.4 → -0.1 | 蓄水 1 轮，泄压 1~2 轮归零 |
| C 深度界内 | g=-5px | 恒为 0 |
| D 贴线 | g≈0 | 冻结不变（维持压力） |

### 2.3 罚项活跃角的实际深度（命中率解释）

λ/ρ 的静态上限可达 g₁/2（g₁ = 第一轮 GN 满步过冲深度，本批数据实测峰值 34px）。但动态上活跃角永远碰不到这个深度：

- **越界的角（g>0)**：粗筛不跳过（d<0 走细算），λ 多大都无所谓
- **λ>0 的界内角**：必然是"刚被压回来"的，深度只有亚像素级（≈0.3px）

所以罚项活跃角的实际深度 ≈ 0.3px——动态阈值的判定阈值 `λf/ρ` 几乎恒为亚像素级，粗筛命中率与 `d > 0` 基本一致，动态判定几乎不损失性能。

## 3. 粗筛成立的充分条件

### 3.1 几何条件：放行区 ⊆ 精细多边形

粗边是弦，精细边界是弦上的折线。折线偏差分两个方向：

- **内凹**（折线缩进弦内）→ 多边形变小 → 放行区可能盖到界外 → **必须覆盖**
- **外凸**（折线超出弦外）→ 多边形变大 → 放行区更保守 → 无害

此外粗边是无限直线，多边形角部区域的半平面判定与真实折线角部存在近似误差，也需要 margin 覆盖。

充分条件：

```
内偏量 = max_k( n_in·(bnd[k]-p0) ) + margin   // max 内凹 + margin
要求:   margin > 角部近似误差
```

内偏量随内凹自适应：严重卷帘快门/LDC 导致内凹增大时，放行区自动收缩，几何正确性构造上成立。

### 3.2 罚项惰性条件：判定式精确处理

由 2.1：跳过条件 `d > λf/ρ` 就是罚项惰性的定义式本身，无需 margin 参与。margin 的职责因此收窄为纯几何（3.1）。

## 4. margin 标定（本批数据）

margin 扫描（粗筛生效状态，判定标准：**内外循环迭代次数与停止时机逐行一致 + 输出字节级一致**）：

| margin | 结果 |
|---|---|
| 2 / 5 | 破防：worst 0.117/0.112px > 0.1px 验收线 |
| 8 / 10 / 15 | 迭代路径微差（worst 正常） |
| **20 / 25 / 50** | **完全一致 ✓** |

真实几何阈值 ≈20px（角部近似误差主导）。取 **margin=50**，2.5 倍余量。

## 5. 已知边界

几何条件依赖"内偏量覆盖折线内凹"：极端 LDC/RS 导致某侧折线内凹超过 margin（50px）时，放行区会盖到界外。本批数据最大内凹 6.2px，余量 8 倍；真出现时可增大 margin（不影响性能：本批数据 margin 5~50 耗时相同）。

罚项惰性无残余风险：判定式 `d > λf/ρ` 对任意 λ/ρ 轨迹精确成立，包括极端瞬态。

## 6. 实现摘要

```cpp
// precomputeBoundary (每帧 4 条粗边):
// Pixel coords are y-down; for this winding the left normal points inward.
n_in = (-dir.y, dir.x);   dir = p1 - p0
bulge = max_k( n_in·(bnd[k] - p0) )   // 只内凹
coarse_edges_[i][e] = {p0, n_in, bulge + 50};

// evaluateSDF (每角 4 次点积):
d = min_e( n_e·(qp - p0_e) - offset_e );
if (d > lambda[i][j] * f / rho) { g_cached = -d; J = 0; continue; }   // 罚项惰性, 跳过节细算
```

注意：粗筛跳过的角报保守值 `-d`，日志中 `max_viol` 行会因此与细算版不同（纯诊断显示，不进任何判定：dphi 判据与 e_feas 均取正部，早停只看符号）。

验证基线：15/15 case 与细算版迭代序列逐行一致（排除 max_viol 诊断行）、输出字节级一致、worst 违例不变（0.073px）、总耗时 -35%（与静态 `d>0` 判定耗时相同）。
