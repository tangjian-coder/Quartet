# SDF 粗筛（Safe-Margin Coarse Test）设计文档

本文档记录 `evaluateSDF` 中粗边界快速通道的设计依据：ALM 乘子 λ 的更新机制、粗筛成立的充分条件、以及 margin 参数的推导。

## 1. 背景

`evaluateSDF` 是求解热点：每帧 4 个 crop 角点 × 40 条精细边界边的距离计算。优化思路：

- 每帧预计算 4 条**粗边**（每侧边界 11 个点的两端连线）+ 内偏量
- 角点先做 4 次点积的粗筛：深度界内（`d > 0`）则报 `g = -d, J = 0`，跳过 40 边细算
- 贴线区才走精细计算

粗筛"跳过细算"要安全，必须同时满足两个断言：

| 断言 | 内容 | 由什么保证 |
|---|---|---|
| 几何正确 | 粗筛放行的角真的在多边形内 | 内偏量 ≥ 折线最大内凹 |
| 罚项惰性 | 跳过的角罚项/梯度确实为零 | 放行深度 > λ/ρ |

## 2. GN + ALM 中的 λ 更新机制

### 2.1 罚项结构

每个角点一条不等式约束 `g ≤ 0`（g = 前向 SDF，界内为负）。ALM 罚项：

```
penalty = max(0, λ + ρ·g)² / (2ρ)
```

- `λ`：拉格朗日乘子（积累的约束压力）
- `ρ`：罚参数（外层每轮 ×2：20→40→80→160→320）

**罚项活跃条件**（对 H/b 有贡献）：

```
λ + ρ·g > 0   ⟺   λ/ρ > |g|      (界内时 g<0, |g| 为深度)
```

即：界内深度小于 λ/ρ 的角，罚项仍活着；深度超过 λ/ρ 的角，罚项为零。

### 2.2 λ 更新与 ρ 更新

```cpp
// 每轮 GN 结束后:
lambda = max(0, lambda + rho * g * inv_f);   // 越界积累压力, 界内泄压
rho = min(rho * 2, rho_max);                 // 无条件翻倍
```

λ 的四种典型轨迹（px 制阈值 `λf/ρ`，即罚项活跃区的深度上限）：

| 场景 | g 的取值 | λ 趋势 |
|---|---|---|
| A 持续越界 | g=+0.4px × 5 轮 | 涨到 λf/ρ ≈ 0.78px（渐近 2·g_max） |
| B 越界后压回 | +0.4 → -0.1 | 蓄水 1 轮，泄压 1~2 轮归零 |
| C 深度界内 | g=-5px | 恒为 0 |
| D 贴线 | g≈0 | 冻结不变（维持压力） |

### 2.3 λ/ρ 的上界推导

ρ 几何增长使早期积累的 λ 被稀释。持续越界 g_max 时：

```
λf/ρ = g_max·(1/16 + 1/8 + 1/4 + 1/2 + 1) ≈ 1.94·g_max ≈ 2·g_max
```

**λ/ρ 上限由瞬时过冲决定，不是稳态**。λ 在每轮越界时积累、被 ρ 的几何增长稀释，峰值出现在第一轮大过冲后的第二轮初：

```
λf/ρ 峰值 ≈ ρ₁·g₁/ρ₂ = g₁/2      (g₁ = 第一轮 GN 满步过冲深度)
```

注意 g₁ 是优化路径属性而非数据属性（raw 恒深度界内，越界是 GN 过冲产生的）。稳态越界（末轮残留）很小（≤0.05px，早停阈值），但瞬时过冲可以很大。

- 本批 15 case 实测：第一轮过冲峰值 34.25px（100900 Win#68）→ λf/ρ 峰值 ≈ 17px
- 极端假想数据：过冲更深 → λf/ρ 峰值同步放大

## 3. 粗筛成立的两个充分条件

### 3.1 几何条件：放行区 ⊆ 精细多边形

粗边是弦，精细边界是弦上的折线。折线偏差分两个方向：

- **内凹**（折线缩进弦内）→ 多边形变小 → 放行区可能盖到界外 → **必须覆盖**
- **外凸**（折线超出弦外）→ 多边形变大 → 放行区更保守 → 无害

充分条件：

```
内偏量 = max_k( n_in·(bnd[k]-p0) ) + margin      // max 内凹 + 余量
```

内偏量随内凹自适应：严重卷帘快门/LDC 导致内凹增大时，放行区自动收缩，几何正确性构造上成立。

### 3.2 罚项惰性条件：放行深度 > λ/ρ

粗筛判定 `d > 0` 放行深度 ≥ 内偏量的角。跳过的角罚项为零要求：

```
内偏量 > λf/ρ   ⟺   内凹_max + margin > 第一轮过冲深度/2
```

两个条件分别由"几何参数"（内偏量）和"优化状态"（λ/ρ）决定——它们是两个独立赛跑的量，margin 必须同时盖住两者。

## 4. 本批数据的验证

| 量 | 实测值 | 来源 |
|---|---|---|
| 最大内凹 | 6.2px | 15 case 全边界扫描 |
| 第一轮过冲峰值 g₁ | 34.25px | 全量 log 扫描（ALM=1 末） |
| λf/ρ 峰值 | ≈17px (g₁/2) | 上式 |
| margin | 50px | 扫描 {5,15,25,30,50} |

```
几何条件:   内偏量 = 6.2 + 50 = 56.2px > 内凹 6.2px   ✓
惰性条件:   56.2px > λf/ρ ≈ 17px                     ✓ 3.3 倍余量
```

margin 扫描结果：{5,15,25,30,50} 输出全部逐字节一致（margin 只影响命中率与安全余量，不影响求解路径）；{5,15,30} 性能相同（深度分布二元，中间档帧稀少），50 慢 ~7%。

**注意**：5px 虽实测一致，但内偏仅 ~11px < λf/ρ 峰值 17px，理论上已破防（深度分布二元恰好掩盖）；15px 余量也仅 1.2 倍。选 50px 是为覆盖 2 倍更极端的过冲，性能代价可忽略。

## 5. 已知边界与根治方案

**margin=50 的失效场景**：若未来数据第一轮过冲超过 ~110px（内偏量 56×2），λ/ρ 峰值将越过内偏量，罚项惰性条件破防。

**根治方案**（动态阈值）：粗筛判定从 `d > 0` 改为

```cpp
double lambda_f = lambda[act_i][j] * focal_length_;
if (d > lambda_f / rho) { g = -d; J = 0; continue; }
```

直接判定罚项惰性本身，对任意数据构造安全。当前未采用：本批数据余量 3.3 倍，静态 margin 更简单。

## 6. 实现摘要

```cpp
// precomputeBoundary (每帧 4 条粗边):
// Boundary is clockwise, so the right normal points inward.
n_in = (dir.y, -dir.x);  dir = p1 - p0
bulge = max_k( n_in·(bnd[k] - p0) )   // 只内凹
coarse_edges_[i][e] = {p0, n_in, bulge + 50};

// evaluateSDF (每角 4 次点积):
d = min_e( n_e·(qp - p0_e) - offset_e );
if (d > 0) { g_cached = -d; J = 0; continue; }   // 99% 的帧走这
```

验证基线：15/15 case 与细算版字节级一致，worst 违例不变（0.073px），总耗时 -35%+。
